# Railway-Management-System
This project is a Railway Management System developed using Django, HTML, CSS, and SQLite, aimed at simplifying the booking, management, and support processes for railway services.
Features:
For Customers:

    Book Tickets: Customers can book tickets for their desired journeys.
    Cancel Tickets: Provides the functionality to cancel previously booked tickets.
    Raise Queries: Allows customers to raise queries for any issues or concerns.
    View Booking History: Customers can view their past bookings and related details.

For Admins:

    Add or Update Trains: Admins can add new trains to the system or modify existing train details.
    View Overall Booking History: Admins can access the overall booking history to track the performance and usage of the system.

For Customer Support Team:

    Assist Customers: A dedicated customer support team is able to assist customers by addressing their queries and issues efficiently.

Technologies Used:

    Backend: Django
    Frontend: HTML, CSS
    Database: SQLite

This project aims to provide a comprehensive solution for managing train bookings, offering a smooth experience for customers, admins, and support staff.
